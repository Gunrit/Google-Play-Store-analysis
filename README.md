Google Play Store Analytics

An end-to-end Data Science project that analyzes app performance, user sentiment, and predicts app ratings using machine learning.

🚀 Features
Interactive dashboard built with Streamlit
App category, rating, and install analysis
Sentiment analysis using VADER (NLP)
Machine learning models (Linear Regression & Random Forest)
Model comparison using R² and MSE
Feature importance analysis
App rating prediction tool
🛠 Tech Stack

Python, Pandas, NumPy, Plotly, Scikit-learn, NLTK, Streamlit
